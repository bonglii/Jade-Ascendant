## Technical boundaries

Profile proof only recognizes a published mail's acknowledged, unresolved claim for the authenticated owner, with matching immutable reward JSON and a positive integer Compass count. Expired/deleted/archived mail UI does not revoke a completed grant. Existing Odyssey outbox deliveries continue to rely on event state and refund checks. Proof reads never grant items or expose email, recipient identities, receipts or balances. Missing service configuration or failure is explicitly unavailable and does not become ownership.

The native Odyssey root envelope is unchanged. Optional verification metadata lives in the existing state object, accepted by the installed native contract. The existing60s lease, Play Integrity, nine production gates and native candidate remain. A new AAB is required for client messages, hints and Realm polish; the server Compass gift fix itself needs only the two Workers.

Masked email metadata is local, bounded and atomic, outside gameplay/cloud domains. Only the last at most four local-part characters and domain are retained after a verified Google callback. It cannot authenticate an account or reconstruct the email of an old unknown owner. It is excluded from the support report.
