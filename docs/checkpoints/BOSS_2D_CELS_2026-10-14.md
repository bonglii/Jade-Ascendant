# Boss 2D cels — 2026-10-14

Replaces the rejected moving illustration presentation for 25 boss identities across all 26 encounters in Realms I–V. Ascended Guardian reuses Guardian art while retaining its encounter patterns.

- Six hand-drawn-style generated cels per walk, melee, aimed projectile, radial release, sky cast and ground shockwave: 900 cels total.
- Atlas grid: 6×6, 960×960; every cell 160×160. Minimum 12 transparent pixels at each edge. AtlasTexture filter_clip enabled. Same packed scale across each boss's poses; feet baseline 148.
- Walk advances by actual travel, never elapsed idle time. Stopped, blocked, casting and dead bosses do not cycle their legs. Generic actor transforms bypass these bosses; hurt color remains.
- Anticipation/release/recovery pose timing follows melee and projectile commitment or the real spell warning duration. Facing is captured during committed actions. Spell family selects forward, outward, ground or sky poses.
- Single and radial projectiles originate above the ground near the drawn upper body/weapon. Shot snapshots, damage, count and patterns remain.
- Visible idle height drives display scaling so transparent padding does not make the boss tiny. Collision shapes remain unchanged.
- Earlier pressure/range/autofire, melee dodge, phase, pause and bounded telegraph fixes are preserved.
- Art provenance and exact base prompts: assets/enemy/boss_2d/asset_sources.json. Built-in imagegen used; runtime PNGs are in the repository. Guardian melee was regenerated as a clean full-weapon strip after native QA revealed a merged-source blade. Two incomplete sheets were supplemented with separately generated six-cel sky strips, then normalized into complete atlases.

## Lessons

1. A requested sprite grid is not proof of the generated grid. Count complete bodies; check every frame border and visually inspect full-body/weapon continuity.
2. Opaque-only main-component extraction can silently amputate disconnected or antialiased weapons. Preserve the connected body-plus-weapon component, and separate only merged effect bridges.
3. Walking cels and a procedural gait must not both own the boss pose. One frame driver owns the whole drawing; actual displacement advances walk.
4. Capturing PNGs is slower than an animation tick. Native contact-sheet footage uses explicit 50ms sample ticks; encounter regression uses actual physics.
5. Keep shared backlog/LESSONS files out of transport patches. Use a dedicated checkpoint and explicit publisher paths; never force-push.
