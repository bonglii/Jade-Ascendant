# Jade Qi Magnet — 13 October 2026

An elite kill drops one jade spiral talisman at each of two authored milestones:
the first elite from wave 4, then the first elite from wave 8. If a stage has no
late elite from wave 8, its last later elite is used. Default stages use 4/8;
alternate schedules such as 3/5/7/8 use 5/8. No enemy schedule is changed.

Touching the token attracts the existing map XP shards, including distant ones.
They travel to the player in approximately 0.65 active gameplay seconds, then
use their existing collection method and its per-shard rounding/multipliers.
The token adds no XP, damage, permanent stat or currency. Later drops follow
normal pickup rules. The existing 160-shard cap and overflow value merge remain.

The artwork is a dedicated shaded jade/gold spiral seal SVG, distinct from the
amber XP shards. Three rotating arcs and a bounded activation ring communicate
the sweep. Reduced-effects settings suppress rotation and the activation ring.
There is no second modal, permanent particle emitter or per-frame map scan.

Awarded milestone waves and positions of uncollected tokens are added to the
existing checkpoint data. Continue restores the tokens without repeating their
awards. Legacy checkpoints create no token and skip elapsed drop milestones.
Ground shard checkpoint behavior stays owned by the existing game.

QA uses a private `jade_magnet_qa` user directory. The smoke suite verifies
real elite death wiring, both Realm IV/V overrides, all 25 stage schedules,
checkpoint save/load, 166 spawned shard values merging into the 160 cap,
per-shard XP modifiers, repeat-contact protection, paused attraction and queued
level-ups through the existing choice animations. Never run against real saves.

Godot 4.7.2 validation: 110 magnet checks and 472 premium combat regression
checks passed, 582 total. Patch application and resulting file contents were
verified against checkpoint commit 6a87ab7. Headless exit/resource warnings
remain from the existing game; there were no script errors or failed checks.

Apply the patch, reopen Godot, then export Android. No backend deploy is needed.
The publisher uses an explicit source:destination fetch refspec, verifies the
commit reference and distinguishes ancestry failures from Git command errors.
It only stages this package on checkpoint/iap-fasttrack-20261010 and prints
the GitHub commit URL after remote SHA verification. Main and IAP stay protected.
