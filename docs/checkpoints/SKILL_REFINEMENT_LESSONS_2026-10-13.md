# Prevent recurrence

- Audit instantiated production scene properties as well as script defaults.
  The real starting HP is 100, not the PlayerHealth script fallback of 10.
- Package changes against an explicit task baseline using a private Git index;
  do not include unrelated staging or shared checkpoint documents.
- Distinguish previously completed runtime checks from checks rerun after a
  session reset. Never represent a recovered workspace as the latest full game.
- Use the full Windows PowerShell path in CMD launchers and return a nonzero
  exit code for publishing failures.
