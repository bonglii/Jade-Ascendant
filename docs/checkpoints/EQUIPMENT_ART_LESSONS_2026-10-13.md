# Equipment art refresh: lessons

- Preserve incremental patch compatibility: never append to shared LESSONS.md or modify prior publisher path lists in a delivered patch. Ship this unique checkpoint plus a dedicated publisher. Validate against a fixture with diverged shared files.
- Inspect every original equipment and its runtime route before regenerating. Exclude Jade Binding Chain and Celestial Returning Glaive by ID, not list position.
- Long horizontal weapons shrink too much in inventory squares. Compile diagonal inventory icons with native Godot while retaining horizontal authored images for the actual projectile. Source PNG bytes remain unchanged.
- Keep large generated source art out of dashboard delivery and runtime imports: use 256 px imports with mipmaps, and shared native compiled icons. Hash source PNGs and verify every catalog mapping.
- A generated Sunfire image included a broad glow; regenerate a clean transparent weapon cutout before integration. Avoid editing source pixels or compensating with gameplay changes.
- Native UI screenshot tools must wait for menu prewarm before quitting; an early teardown can interrupt background scene loads. Production source is not changed for the fixture.
